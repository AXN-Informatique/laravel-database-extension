Installation
============

Requirements
------------

- PHP 8.4+
- Laravel 12+

Install via Composer
--------------------

```bash
composer require axn/laravel-database-extension
```

The service provider `Axn\Illuminate\Database\ServiceProvider` is automatically discovered by Laravel thanks to package auto-discovery.

No additional configuration is required. All features are available immediately after installation.

Version compatibility
---------------------

| Package version | PHP version | Laravel version |
|-----------------|-------------|-----------------|
| 5.x             | 8.4+        | 12+             |
| 4.x             | 8.2+        | 10+             |
| 3.x             | 8.0+        | 8+              |
| 2.x             | 7.x         | 5.x - 7.x       |
